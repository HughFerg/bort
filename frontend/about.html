About

What is Flanderize?

A visual search engine for The Simpsons. Describe a scene, a mood, a visual — and it finds the matching frame. Every indexed episode is searchable by what's actually happening on screen, not just quotes or episode titles.

How does it work?

Each frame is encoded into a vector embedding using CLIP, a neural network trained to understand images and text together. When you search, your query is embedded the same way and compared against every frame. The closest matches win.

Why does it sometimes return weird results?

CLIP understands visual concepts, not Simpsons lore. Searching for a character's name won't help — describe what you see instead. "Man in white shirt looking surprised" will beat "Homer" every time.
